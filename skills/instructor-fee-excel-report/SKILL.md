# 강사료 정산 엑셀 자동화 (구글폼 입력 → 이메일 전송)

강사님들과의 일상 소통은 기존처럼 카카오톡으로 유지하고, 수업시간 제출만 구글폼으로 받는다.
구글폼 응답(구글시트에 쌓임)을 바탕으로 강사료를 계산해 엑셀로 정리한 뒤, 원장님(사용자) 본인 이메일로
보내는 스킬입니다.

## 언제 사용하는가

- "강사들 수업시간 걷어서 강사료 정리해줘"
- "이번 달 강사료 엑셀로 뽑아서 메일로 보내줘"
- "구글폼 응답 정리해서 강사료 정산표 만들어줘"

## 전체 흐름

1. **입력 수집** — 구글폼으로 받은 강사별 수업시간 데이터를 확보한다(구글시트 응답을 CSV로 받음).
2. **강사료 계산** — 수업시간 × 시급 × 1.5로 총액을 계산하고, 3.3% 원천징수를 뺀 실지급액까지 계산한다.
3. **엑셀 생성** — 서식이 있는 `.xlsx` 파일로 저장한다.
4. **전달** — 완성된 엑셀 파일을 사용자 이메일로 첨부해 보낸다.

---

## 1. 입력 데이터 형식 — 구글폼

강사들에게 수업시간 제출용 구글폼 링크를 카톡으로 공유한다. 폼 질문은 아래 컬럼과 1:1로 맞춘다
(질문 순서와 이름을 맞춰두면 응답 시트를 그대로 CSV로 써먹을 수 있다).

| 컬럼명(폼 질문) | 필수 | 설명 | 예시 |
| --- | --- | --- | --- |
| 강사명 | O | 강사 이름 | 김민지 |
| 과목 | X | 담당 과목/반 | 중등수학 |
| 수업시간 | O | 이번 달 총 수업 시간(시간 단위) | 32 |
| 시급 | O | 시간당 기본 단가 | 30000 |
| 비고 | X | 특이사항 | 대체수업 2회 포함 |

응답을 CSV로 받는 방법:
- 구글폼 → "응답" 탭 → 연결된 구글시트 열기 → 파일 > 다운로드 > 쉼표로 구분된 값(.csv)
- (Drive/Sheets 연동 도구를 쓸 수 있는 세션이면) 응답 시트를 직접 읽어와 CSV로 저장해도 된다.
- "타임스탬프" 등 폼이 자동으로 붙이는 컬럼은 무시하고, 위 표의 컬럼명만 있으면 된다. 컬럼명이 다르면
  `scripts/generate_report.py`에 넣기 전에 헤더를 표에 맞게 바꿔준다.

이 형식의 CSV 예시는 `scripts/sample_input.csv` 참고.

## 2. 강사료 계산 규칙 (고정)

이 학원의 강사료 계산식은 다음과 같이 고정되어 있다.

- 총 강사료 = `수업시간 × 시급 × 1.5`
- 원천징수액 = 총 강사료 × 3.3% (사업소득세 3% + 지방소득세 0.3%, 원 단위 절사)
- 실지급액 = 총 강사료 − 원천징수액

즉 실지급액 = `수업시간 × 시급 × 1.5 × (1 − 0.033)`. 이 공식은 기본값이며, 별도 언급이 없는 한
항상 이 방식으로 계산한다.

## 3. 엑셀 생성

`scripts/generate_report.py`를 사용한다.

```bash
python3 scripts/generate_report.py --input 입력.csv --output "강사료_정산_2026-09.xlsx" --month "2026년 9월"
```

- 컬럼 구성: 강사명, 과목, 수업시간, 시급, 총강사료(수업시간×시급×1.5), 원천징수(3.3%), 실지급액, 비고
- 출력 파일에는 다음이 포함된다: 헤더 서식(굵게, 배경색), 통화 서식(#,##0원), 강사별 행, 합계 행.
- openpyxl이 필요하다: `pip install openpyxl`

스크립트가 없는 환경(xlsx 스킬을 쓰는 에이전트 세션)이라면, 위 "2. 강사료 계산 규칙"대로 직접
xlsx 스킬을 이용해 동일한 컬럼 구성의 엑셀을 생성해도 된다.

## 4. 전달 — 이메일 (기본 방식)

엑셀 파일을 그대로 첨부해서 보낸다.

- Gmail MCP 도구(`mcp__Gmail__send_message` 등)를 사용할 수 있는 세션이면 그 도구로 xlsx 파일을 첨부해 보낸다.
  받는 사람 주소를 사용자가 따로 지정하지 않으면, 세션에 등록된 사용자 본인 이메일로 보낸다.
- 별도 MCP 없이 SMTP만 있는 환경이면 `scripts/send_email.py`를 사용한다.

```bash
python3 scripts/send_email.py \
  --to "원장님메일@example.com" \
  --subject "2026년 9월 강사료 정산" \
  --body "9월 강사료 정산표 보내드립니다." \
  --attachment "강사료_정산_2026-09.xlsx"
```

- 이 스크립트는 Gmail 기준 앱 비밀번호(App Password) 사용을 전제로 한다. 환경변수로 다음을 설정한다.
  - `SMTP_EMAIL` : 보내는 사람 Gmail 주소
  - `SMTP_APP_PASSWORD` : Google 계정의 앱 비밀번호(2단계 인증 필요, 일반 로그인 비밀번호 아님)

## 5. 예시 대화 흐름

1. 사용자: "강사들 이번 달 수업시간 정리해서 메일로 보내줘. 원천징수는 떼줘."
2. 에이전트: 구글폼 응답 시트를 CSV로 받아온다(또는 사용자가 이미 전달한 CSV를 사용).
3. 에이전트: `generate_report.py`로 엑셀 생성 (시간×시급×1.5, 3.3% 세금 공제 자동 반영)
4. 에이전트: `send_email.py` 또는 Gmail 도구로 사용자 본인 이메일에 엑셀 첨부 발송
5. 에이전트: 완료 후 총 강사료 합계, 강사 수를 한 줄로 요약해서 보고

## 6. 참고 — 카카오톡으로 보내고 싶어질 경우 (현재는 미사용)

지금은 구글폼 입력 + 이메일 전송으로 충분하지만, 나중에 카카오톡으로 직접 받고 싶어지면 두 가지
선택지가 있다.

- **개인 카카오톡 "나에게 보내기"**: 파일 첨부는 불가능하고, 엑셀을 클라우드(Google Drive 등)에 올려
  받은 링크를 텍스트 메시지로 보내는 방식만 가능하다. 카카오 로그인으로 액세스 토큰을 발급받아야 한다.
- **카카오톡 비즈니스 채널(알림톡/친구톡)**: 채널이 있으면 원장님뿐 아니라 강사님들에게 개별 정산
  결과를 직접 보낼 수 있지만, 비즈엠·알리고 등 발송대행사 연동과 (알림톡이면) 템플릿 사전 심사가 필요하다.

필요해지면 이 부분을 다시 요청하면 된다.

## 주의사항

- 강사 개인정보(계좌번호 등)는 이 스킬의 처리 대상이 아니다. 필요하면 별도 보안 채널로 관리한다.
- 원천징수율(3.3%)은 프리랜서/사업소득 기준 일반값이다. 4대보험 가입 강사 등 다른 계약 형태는 세율이
  다를 수 있으므로 실제 적용 전 사용자에게 확인한다.
