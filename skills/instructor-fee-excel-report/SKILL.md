# 강사료 정산 엑셀 자동화 & 카톡/메일 전송

학원 강사들이 제출한 "이번 달 수업시간(또는 수업 횟수)"을 받아서 강사료를 계산하고,
보기 좋은 엑셀 파일로 정리한 뒤 원장님(사용자) 본인에게 카카오톡 또는 이메일로 보내는 스킬입니다.

## 언제 사용하는가

- "강사들 수업시간 걷어서 강사료 정리해줘"
- "이번 달 강사료 엑셀로 뽑아서 카톡으로 보내줘"
- "강사료 정산표 만들어서 메일로 보내줘"

## 전체 흐름

1. **입력 수집** — 강사별 수업시간(또는 횟수)과 단가 데이터를 확보한다.
2. **강사료 계산** — 단가 × 시간(또는 횟수)로 총액을 계산하고, 필요 시 원천징수(3.3%)를 반영한 실지급액까지 계산한다.
3. **엑셀 생성** — 서식이 있는 `.xlsx` 파일로 저장한다.
4. **전달** — 카카오톡("나에게 보내기") 또는 이메일로 완성된 엑셀 파일을 보낸다.

---

## 1. 입력 데이터 형식

강사들에게 아래 항목만 받으면 된다.

- **권장 방식**: 강사님들과의 일상 소통은 기존처럼 카카오톡으로 유지하되, 수업시간 제출만 구글폼
  링크를 카톡으로 공유해서 받는다. 카카오톡 개인/그룹 채팅은 공식 API로 메시지를 읽어올 방법이 없으므로,
  자동 정산을 하려면 응답이 구글시트에 쌓이는 구글폼(또는 네이버폼)이 가장 현실적이다.
- 강사 수가 적거나 폼 도입 전이면, 카톡으로 받은 텍스트를 사람이(또는 에이전트가) 아래 표 형식(CSV)으로
  옮겨 적어도 된다.

| 컬럼명 | 필수 | 설명 | 예시 |
| --- | --- | --- | --- |
| 강사명 | O | 강사 이름 | 김민지 |
| 과목 | X | 담당 과목/반 | 중등수학 |
| 수업시간 | O | 이번 달 총 수업 시간(시간 단위) | 32 |
| 시급 | O | 시간당 기본 단가 | 30000 |
| 비고 | X | 특이사항 | 대체수업 2회 포함 |

이 형식의 CSV 예시는 `scripts/sample_input.csv` 참고. 사용자가 카카오톡 대화나 문자로 비정형 텍스트를
보내주면, 위 표 형식(CSV)으로 먼저 정리한 뒤 다음 단계로 넘어간다.

## 2. 강사료 계산 규칙 (고정)

이 학원의 강사료 계산식은 다음과 같이 고정되어 있다.

- 총 강사료 = `수업시간 × 시급 × 1.5`
- 원천징수액 = 총 강사료 × 3.3% (사업소득세 3% + 지방소득세 0.3%, 원 단위 절사)
- 실지급액 = 총 강사료 − 원천징수액

즉 실지급액 = `수업시간 × 시급 × 1.5 × (1 − 0.033)`. 이 공식은 기본값이며, 별도 언급이 없는 한
항상 이 방식으로 계산한다.

## 3. 엑셀 생성

`scripts/generate_report.py`를 사용한다.

```bash
python3 scripts/generate_report.py --input 입력.csv --output "강사료_정산_2026-09.xlsx" --month "2026년 9월"
```

- 컬럼 구성: 강사명, 과목, 수업시간, 시급, 총강사료(수업시간×시급×1.5), 원천징수(3.3%), 실지급액, 비고
- 출력 파일에는 다음이 포함된다: 헤더 서식(굵게, 배경색), 통화 서식(#,##0원), 강사별 행, 합계 행.
- openpyxl이 필요하다: `pip install openpyxl`

스크립트가 없는 환경(xlsx 스킬을 쓰는 에이전트 세션)이라면, 위 "2. 강사료 계산 규칙"대로 직접
xlsx 스킬을 이용해 동일한 컬럼 구성의 엑셀을 생성해도 된다.

## 4. 전달 — 이메일 (권장, 첨부파일 그대로 전송 가능)

엑셀 파일을 그대로 첨부해서 보낼 수 있는 가장 확실한 방법이다.

- Gmail MCP 도구(`mcp__Gmail__send_message` 등)를 사용할 수 있는 세션이면 그 도구로 xlsx 파일을 첨부해 보낸다.
- 별도 MCP 없이 SMTP만 있는 환경이면 `scripts/send_email.py`를 사용한다.

```bash
python3 scripts/send_email.py \
  --to "원장님메일@example.com" \
  --subject "2026년 9월 강사료 정산" \
  --body "9월 강사료 정산표 보내드립니다." \
  --attachment "강사료_정산_2026-09.xlsx"
```

- 이 스크립트는 Gmail 기준 앱 비밀번호(App Password) 사용을 전제로 한다. 환경변수로 다음을 설정한다.
  - `SMTP_EMAIL` : 보내는 사람 Gmail 주소
  - `SMTP_APP_PASSWORD` : Google 계정의 앱 비밀번호(2단계 인증 필요, 일반 로그인 비밀번호 아님)

## 5. 전달 — 카카오톡

두 가지 방식이 있다. 이미 카카오톡 비즈니스 채널(카카오톡 채널)을 운영 중이라면 **5-B(비즈니스 채널)**를
우선 검토한다 — 원장님 본인뿐 아니라 강사님들에게 직접 정산 결과를 보낼 수 있어 확장성이 좋다.

### 5-A. 개인 카카오톡 "나에게 보내기" (원장님 본인에게만, 설정 간단)

카카오톡 메시지 API는 임의의 바이너리 파일(xlsx)을 직접 첨부하는 기능을 제공하지 않는다.
따라서 아래 순서로 처리한다.

1. 엑셀 파일을 다운로드 가능한 링크로 만든다. (예: Google Drive에 업로드 후 공유 링크 생성 — Drive MCP 도구가
   있으면 `mcp__Google_Drive__create_file` 등으로 업로드하고 공유 링크를 받는다.)
2. 그 링크를 담아 카카오톡 "나에게 보내기" 텍스트 템플릿 메시지를 발송한다. `scripts/send_kakao.py` 사용.

```bash
python3 scripts/send_kakao.py \
  --text "9월 강사료 정산표가 준비됐습니다. 아래 링크에서 확인하세요." \
  --link "https://drive.google.com/..."
```

- 사전 준비 (최초 1회):
  1. [Kakao Developers](https://developers.kakao.com)에서 애플리케이션 생성 → REST API 키 확인
  2. "카카오 로그인" 활성화, 동의항목에서 `talk_message`("카카오톡 메시지 전송") 활성화
  3. 카카오 로그인으로 인가 코드 → 액세스 토큰/리프레시 토큰 발급 (본인 계정으로 1회 로그인)
  4. 환경변수 `KAKAO_ACCESS_TOKEN`에 발급받은 액세스 토큰 저장 (만료되면 리프레시 토큰으로 재발급 필요)
- 액세스 토큰 발급/갱신은 카카오 OAuth 특성상 브라우저 로그인이 필요해 완전 자동화는 어렵다. 최초 설정만
  사용자가 직접 하고, 이후 토큰 갱신은 리프레시 토큰으로 백엔드에서 처리하는 구조를 권장한다.
- 용도: 원장님 본인이 정산 결과를 확인하는 용도로만 적합. 강사님들에게 개별 발송은 안 됨(개인 계정 API는
  "나에게 보내기"만 지원).

### 5-B. 카카오톡 비즈니스 채널 (알림톡/친구톡) — 강사님들에게 직접 발송 가능

카카오톡 채널(비즈니스 계정)이 있으면 정식 비즈니스 메시지로 원장님 또는 강사님 각각에게 정산 결과를
직접 보낼 수 있다. 다만 카카오가 API를 직접 열어주는 게 아니라, 카카오와 제휴한 **발송대행사**(예:
비즈엠, 알리고, NHN Toast, 인포뱅크 등)의 API를 통해 보낸다.

- **알림톡**: 사전에 카카오 심사를 받아 승인된 템플릿 문구만 발송 가능(자유 문구 불가), 파일 첨부는 불가하고
  링크(버튼)는 넣을 수 있다. 정보성 메시지(정산 결과 알림)에 적합하고 발송비가 저렴하다.
- **친구톡**: 채널을 "친구 추가"한 사람에게만 발송 가능하지만 이미지·자유 문구·링크 버튼을 자유롭게 구성할
  수 있다. 강사님들이 학원 채널을 친구 추가해두면 "이번 달 강사료 정산 결과 - [엑셀 보기]" 같은 메시지를
  각자에게 개별 발송할 수 있다.
- 준비할 것: 카카오톡 채널 관리자센터에서 발송대행사 연동 신청 → 발송대행사로부터 API 키/발신 프로필 키
  발급 → (알림톡이면) 템플릿 사전 등록·심사 통과.
- 이 경로는 발송대행사마다 API 스펙이 달라 이 스킬에는 범용 스크립트를 포함하지 않는다. 실제 연동 시,
  사용 중인 발송대행사 이름을 알려주면 그에 맞는 발송 스크립트를 추가로 작성한다.
- 강사료처럼 금액이 포함된 정보를 다수에게 보낼 때는, 파일을 통째로 보내기보다 "본인 정산 내역"만 담긴
  개인별 요약 메시지 + (필요시) 개인별 보기 링크로 나눠 보내는 것을 권장한다(다른 강사 급여 노출 방지).

## 6. 예시 대화 흐름

1. 사용자: "강사들 이번 달 수업시간 정리해서 카톡으로 보내줘. 원천징수는 떼줘."
2. 에이전트: 강사별 수업시간/단가 데이터를 요청하거나, 이미 전달받은 데이터를 CSV로 정리
3. 에이전트: `generate_report.py`로 엑셀 생성 (시간×시급×1.5, 3.3% 세금 공제 자동 반영)
4. 에이전트: 엑셀을 업로드하고 링크를 만든 뒤 `send_kakao.py`로 "나에게 보내기" 발송
   (또는 사용자가 메일을 원하면 `send_email.py`로 첨부 발송)
5. 에이전트: 완료 후 총 강사료 합계, 강사 수, 발송 채널을 한 줄로 요약해서 보고

## 주의사항

- 강사 개인정보(계좌번호 등)는 이 스킬의 처리 대상이 아니다. 필요하면 별도 보안 채널로 관리한다.
- 원천징수율(3.3%)은 프리랜서/사업소득 기준 일반값이다. 4대보험 가입 강사 등 다른 계약 형태는 세율이
  다를 수 있으므로 실제 적용 전 사용자에게 확인한다.
- 카카오톡 액세스 토큰은 만료(보통 6시간~수개월, 앱 설정에 따라 다름)되므로, 발송 실패 시 토큰 재발급
  안내를 먼저 확인한다.
